# Bank-data-analysis

**Project Overview**
• A Python-based data analysis project that analyzes customer banking data stored in a CSV file. The project focuses on data cleaning, customer analysis,     
  statistical calculations, and visualization.

**Key Features**
• Data Cleaning and Preprocessing
• Null and Duplicate Value Handling
• Customer Data Filtering
• City-wise Account Balance Analysis
• Credit Score Statistical Analysis
• High-value and Risk Customer Identification
• Correlation Analysis
• Data Sorting and Grouping
• Pivot Table Analysis
• Data Visualization

**Technology Stack**

Python | Pandas | NumPy | Matplotlib | CSV

**Core Concepts**
• Data Cleaning 
• Filtering 
• GroupBy 
• Pivot Table 
• Statistical Analysis 
• Correlation 
• NumPy Arrays 
• Data Visualization
 
**Visualizations**
• Created Line Chart, Bar Chart, Scatter Plot, Histogram and Box Plot to understand banking data graphically.
 
**Project Objective**
•The main objective is to analyze customer age, account balance, credit score, and city-wise banking data and identify useful patterns and insights using Python.
 
**Project Type: Banking Data Analysis Project**

**Language: Python**

**Storage: CSV File**

**Libraries: Pandas, NumPy, Matplotlib**
